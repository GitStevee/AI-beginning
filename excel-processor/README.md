# Excel Processor

Универсальный обработчик Excel-файлов через Telegram.

## Что умеет
- Чтение: структура, листы, статистика
- Модификация: колонки/строки, значения, формулы
- Объединение: merge/join нескольких файлов
- Разделение: по колонке, по листам
- Создание: таблицы с нуля
- Расчёты: groupby, pivot, агрегации
- Формулы: с пересчётом через LibreOffice
- Экспорт: xlsx <-> csv

## Архитектура
Telegram -> Hermes -> skill excel-processor
        -> shell MCP -> Python (pandas + openpyxl)
        -> результат в Telegram

## Инструменты (автоматический выбор)
- pandas — аналитика, группировки, merge
- openpyxl — формулы, форматирование, низкоуровневые операции
- xlrd — старые .xls файлы
- xlsxwriter — создание с графиками
- LibreOffice (headless) — recalc формул

## Правила безопасности
- Бэкап перед перезаписью (обязательно)
- Показ структуры ДО модификации
- Спрашивает перед деструктивными операциями
- Чанки для больших файлов (>50k строк)

## Использование
"покажи содержимое отчёт.xlsx"
"объедини продажи.xlsx и товары.xlsx по id_товара"
"раздели клиентов.xlsx по регионам"
"добавь колонку с формулой и пересчитай"
"посчитай средний чек по месяцам"
