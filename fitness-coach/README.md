# Fitness Coach

Трекер тренировок с аналитикой прогресса.

## Что делает
- Запись тренировок в CSV (дата, упражнение, подходы/повторы/вес/RPE)
- Построение графиков: вес, оценочный 1RM (формула Эпли), объём, частота
- Миграция данных из Excel

## Tech stack
- Python 3.12
- matplotlib (графики)
- CSV как единый источник правды

## Установка

bash
pip install matplotlib openpyxl


## Использование

bash
# Запись тренировки
python3 log_workout.py bench_press 4 8 105 8

# График прогресса
python3 plot_progress.py bench_press


## Интеграция
Работает как Hermes-skill: бот в Telegram записывает тренировки
по текстовой команде и показывает графики.

Пример команды: "Запиши: жим лёжа 4×8 @ 105кг RPE 8"
